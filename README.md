# 🎡 Picksy.exe
### Can't decide? Let fate pick for you. ♡

**Picksy.exe** is a playful, mobile-friendly decision-making application inspired by Y2K desktop interfaces, pixel art, and retro arcade aesthetics.

Designed and developed by **Mariah Crafts**, Picksy.exe transforms everyday indecision into an interactive experience through a customizable spinning wheel.

## ✦ Features

- **Interactive Decision Wheel:** Spin an animated wheel to randomly select an option.
- **Custom Choices:** Add and remove options to personalize each decision.
- **Quick Presets:** Choose from predefined categories such as food, games, and weekend activities.
- **Local Storage:** Preserve your choices between browser sessions.
- **Responsive Interface:** Designed for mobile and desktop screens.
- **Retro Visual Design:** Y2K-inspired window chrome, pixel details, pink gradients, and gothic accents.
- **Microinteractions:** Animated buttons, floating hearts, ambient lighting, and result reveals.
- **Reduced-Motion Styling:** Supports reduced-motion preferences for decorative animations.

## ✦ Design Process

### 01. UI/UX Prototype

The project began with a mobile-first Figma prototype exploring a hybrid visual style combining retro desktop software with playful arcade interfaces.

The design emphasizes recognizable controls, readable typography, visual hierarchy, and a distinctive pink-and-black identity.

### 02. Functional Development

The prototype was translated into a functional web application using HTML, CSS, and vanilla JavaScript.

The application includes a canvas-rendered decision wheel, randomized selection logic, editable choices, browser-based persistence, and responsive layouts.

### 03. Testing & Deployment

The application was prepared for desktop and mobile browser testing, with responsive layouts, interactive controls, and animated visual details.

The project is deployed through Vercel.

## ✦ Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or launch it using Live Server.
4. Add choices, select a preset, and spin the wheel!

No backend or additional dependencies are required.
